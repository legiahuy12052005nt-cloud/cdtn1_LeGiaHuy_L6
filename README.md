# 1. Giới thiệu dự án
- Tên dự án: Kho dữ liệu bán hàng và báo cáo doanh thu
- Luồng nghiệp vụ: L6 -(DA)
- Mục tiêu: Trích xuất, làm sạch dữ liệu từ các file Excel và xây dựng Dashboard báo cáo.

# 2. Hướng dẫn chạy dự án
1. Clone repository về máy.
2. Cài đặt Python và các thư viện trong requirements.txt (nếu có).
3. Chạy script ETL: `python src/etl/smoke_test.py`
4. Mở Power BI để xem Dashboard.
